# Vice City Launch Lab — GTA VI fan tools

A static, mobile-friendly **unofficial** GTA VI fan website with a launch countdown, shareable vibe quiz, and adjustable budget calculator. No API keys, backend, npm, or paid hosting required.

## Publish on GitHub Pages

1. Sign up or sign in at https://github.com.
2. Create a **public repository** named `vicecity-launch-hub`.
3. Upload every file from this folder directly to the root of that repository (not inside another folder), commit to the `main` branch.
4. Open **Settings > Pages > Build and deployment**; select **Deploy from a branch**; branch `main`, folder `/(root)`, then Save.
5. Your website should appear at `https://YOUR-USERNAME.github.io/vicecity-launch-hub/` once published. Replace `YOUR-USERNAME` in the `index.html` canonical URL with your actual GitHub username.
6. Prefer a custom domain before applying for AdSense and verify current AdSense site/domain eligibility and GitHub Pages hosting rules.

## Before public launch / AdSense application

- Replace `[OWNER: ...]` contact placeholders in `about.html`, `privacy.html` and `terms.html` with a real contact method.
- Update privacy disclosures for any analytics, ads, consent management and cookies you actually add. Do not copy the starter policy unchanged if you change the site's data practices.
- Add more original, helpful GTA VI guides and carefully maintained information. One interactive page alone does **not** guarantee AdSense approval.
- Check Google AdSense program policies, consent requirements, site ownership verification, and eligibility before adding real ad code. No ads are currently implemented. Don't click your own ads or use incentivized/invalid traffic.
- This is an **unofficial fan site**. Avoid unlicensed Rockstar promotional artwork, logos, music, gameplay reuploads and false claims of affiliation.
- The release timer uses the visitor's local midnight on November 19, 2026. Verify official timing as it changes.

## Files

- `index.html`: launch page, quiz, calculator
- `app.js`: timer, quiz, calculator, share controls
- `style.css`: responsive look
- `guide.html`: original launch checklist
- `about.html`, `privacy.html`, `terms.html`: starter editorial and policy pages
